# Luran Xia · AI 营销工作台

[打开网页](https://luran-xia.github.io/luran-ai-marketing/)

## 连接方式

公开文件中不含真实 API Key。`config.json` 只包含百炼接口地址、默认模型和可选的共享后台地址 `apiBase`。

- 个人连接：页底“连接设置”输入北京地域 Key。默认仅当前页面使用；可明确选择保存在自己的浏览器，刷新后自动连接。密钥仅在调用时直接发送给阿里云，可随时清除本机保存。请勿在公共设备保存。
- 共享服务：在后台保存 `DASHSCOPE_API_KEY`，然后将公开的 `apiBase` 配为后台 HTTPS 地址。访客不需填写 Key。后台必须验证功能和输入、限制调用频率与用量；静态 GitHub Pages 不能保密共享密钥。

目前 `apiBase` 留空，不代表共享后台已经开通。个人连接无需 Cloudflare，也不会把密钥上传 GitHub。输入、结果和聊天仅保留在页面内存；只有用户明确选择保存时，个人密钥才写入该浏览器的 localStorage。

所有者账号已核对 qwen-flash 免费额度“用完即停”为开启状态。网页限制只能减少正常操作的消耗；实际计费与停用以百炼账号设置为准。停止使用时可在百炼撤销对应 Key。

页面输入会发送给阿里云处理，请勿提交客户隐私或合同等敏感材料。

## 本地修改与发布

使用 Node.js 22.13+：

```sh
npm install
npm run check
npm run build
```

构建脚本将样式和脚本内联进 `index.html`，无需 GitHub Actions 安装依赖。提交更新后的源码、`index.html` 与 `config.json`，GitHub Pages 从 main 根目录发布；保留 `.nojekyll`。`node_modules`、`.build`、临时配置与上级求职目录不应上传。

主要文件：App.tsx（交互）、marketing.ts（功能定义与内置指令）、styles.css（响应式界面）、config.json（连接）、build.mjs（静态构建）。

# Luran Xia · AI 营销工作台

[在线使用：魔搭国内版](https://modelscope.cn/studios/LURANXIA/luran-ai-marketing) · [GitHub入口](https://luran-xia.github.io/luran-ai-marketing/)

包含11个营销工具和通用聊天，分为甲方、乙方、通用助手三个视角。功能包括营销Brief、定位与卖点、提案评估、营销复盘、案例分析、创意提案、文案分析与改写、活动策划、内容排期、会议整理。提示词已内置，填写材料后直接生成。

网页和后台部署到魔搭Docker创空间，后台调用阿里云北京业务空间的qwen-flash。访客无需登录或配置密钥。真实密钥仅保存在平台Secret中，源码不包含密钥。全站共享体验额度每日100次、每分钟10次，UTC日期重置；免费空间可能休眠，唤醒需要等待。

[国内版完整源码及运行文件](modelscope-source.zip) 可下载审阅。解压后的modelscope-app含前端、服务端、内置提示词与部署说明；dist内5个文件可直接上传到Docker创空间根目录。仓库根目录原前端文件保留用于查看项目发展过程；当前运行版本以部署包为准。
